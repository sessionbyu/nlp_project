## 负面情感测试文本

### 简短负面（10-50字）

1. **生活困扰**
   ```
   今天天气糟透了，下雨降温，出门特别不方便。
   等了半个小时的公交还没来，上班要迟到了。
   手机突然死机，重要的照片和数据都找不回来了。
   晚上失眠到三点，第二天精神特别差。
   ```

2. **工作压力**
   ```
   项目 deadline 临近，连续加班一周，身心俱疲。
   会议被批评，方案被全盘否定，心情很低落。
   同事间的沟通出现问题，导致工作进展缓慢。
   客户临时变更需求，之前的努力白费了。
   ```

3. **学习挫折**
   ```
   考试发挥失常，成绩很不理想，对自己很失望。
   论文被多次驳回，不知道问题出在哪里。
   面试表现糟糕，没能抓住期待的机会。
   学习进度落后，压力越来越大。
   ```

### 中等长度负面（50-200字）

4. **服务质量投诉**
   ```
   这次的网购体验真的太糟糕了！下单时承诺次日达，结果三天才收到货。
   收到商品后发现包装破损，产品表面有明显划痕，质量堪忧。
   联系客服投诉，却被告知需要自行承担运费退换，态度极其恶劣。
   作为老顾客，这种服务态度让我大失所望，以后再也不会光顾了。
   ```

5. **电影差评**
   ```
   抱着很大期待去看这部热门电影，结果大失所望。
   剧情逻辑混乱，情节转折毫无铺垫，看得一头雾水。
   演员表演浮夸，台词尴尬，完全无法入戏。
   三个小时的时长，至少有三分之一的内容可以删掉。
   特效虽然不错，但空洞的剧情根本撑不起这部作品。
    ```

### 长文本负面（200-500字）

6. **工作困境**

   周末也要随时待命处理工作消息，身体开始出现各种预警信号：
   失眠、脱发、颈椎疼痛。更让人沮丧的是，
   尽管付出了这么多努力，项目成果却没有得到应有的认可。

## 📝 使用说明

### 情感预测测试

| 测试文本 | 预期情感 | 推荐模型 |
|---------|---------|---------|
| 正面情感测试文本 1-7 | 正面 (Positive) | BERT / VADER |
| 负面情感测试文本 1-6 | 负面 (Negative) | BERT / VADER |
| 中性情感测试文本 1-5 | 中性 (Neutral) | BERT (更准确) |
| 混合情感测试文本 1-3 | 混合/中性 | BERT |

### 文本增强分析测试

| 测试场景 | 推荐文本 | 测试重点 |
|---------|---------|---------|
| 关键词提取 | 中等长度正面文本 | 关键词权重、频率 |
| 情感分析 | 混合情感文本 | 情感标签、强度、关键词 |
| 文本摘要 | 长文本 (200+字) | 摘要生成质量 |
| 文本统计 | 各类文本 | 字符、词、句子、段落数 |
